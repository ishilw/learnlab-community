# Claude Code configuration

This directory holds the Claude Harness Engine core profile (plugin claude_harness_eng_v6, version 3.0.0), integrated selectively. It contains the Harness agents, skills, hooks, scripts, and configuration, plus its state and trust files.

Project-specific agents, skills, and commands are not yet authored. They are added in their own reviewed increments (see docs/implementation-plan.md, Increment 15).

Nothing here is part of the LMS runtime. See CLAUDE.md, Claude Harness Engine integration, and Future capstone capabilities.

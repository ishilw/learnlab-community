# LearnLab

LearnLab is a lightweight Learning Management System (LMS) built with React, TypeScript, FastAPI, and SQLite.

The application supports course creation, learning content management, student enrollment, quizzes, assessments, and progress tracking.

## Features

- Course catalog and course discovery
- Course search by title or description
- Course creation and management
- Student enrollment
- Lesson and module management
- Quiz authoring and assessments
- Learning progress tracking
- Instructor progress reports
- Role-based access controls

## Technology Stack

| Component | Technology |
|-----------|------------|
| Frontend | React, TypeScript, Vite |
| Backend | Python, FastAPI |
| Database | SQLite |
| Backend Testing | pytest |
| Frontend Testing | Vitest |
